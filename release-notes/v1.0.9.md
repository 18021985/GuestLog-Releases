# Guest Response Log 1.0.9

## Improvements

- Prevents ID OCR from remaining at `Loading language traineddata 0%` by adding bounded startup, retry, cancellation, and fallback handling.
- Improves passport MRZ parsing and repairs common OCR filler noise without adding the noise to guest names.
- Improves Qatar ID and residence permit parsing so country labels and nationality values are not merged into first or last names.
- Simplifies the OCR review screen to show the document fields staff need to verify.
- Keeps scanner and OCR processing on the Windows PC, with scanner and Windows OCR endpoints restricted to localhost.
- Blocks databases, backups, certificates, and other private paths from the local web server.

## Requirements

- Windows 10 or 11 x64.
- Direct scanner capture requires a Windows WIA-compatible scanner driver.
- Windows OCR fallback requires a Windows OCR language pack. The packaged Tesseract engine remains available for local OCR.
