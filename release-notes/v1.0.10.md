# Guest Response Log 1.0.10

## Improvements

- Adds a mobile-friendly Progressive Web App layout with install support, safe-area handling, offline status, and a clear update prompt.
- Includes the packaged OCR engine and English trained data in the hosted build so browser OCR does not depend on a third-party download.
- Adds an administrator-only desktop-to-cloud sync workflow with cloud version checks, a database lock, an automatic private backup, and checksum verification.
- Syncs protected account settings and encrypted visitor ID files without saving cloud credentials on the PC.
- Preserves the improved passport and Qatar ID OCR parsing and the simplified professional review screen.
- Keeps scanner capture and Windows OCR on the Windows PC while allowing hosted browser OCR for uploaded or photographed documents.
- Strengthens hosted security headers and prevents databases, backups, identity documents, credentials, and signing files from entering the Netlify build.

## Requirements

- Windows 10 or 11 x64 for the desktop application.
- Chrome, Edge, or Safari for the hosted PWA.
- Direct scanner capture requires the Windows desktop application and a WIA-compatible scanner driver.
- The hosted PWA requires an internet connection to read or update the cloud database.
